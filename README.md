# Tokyo Quantum Gateway

Top page for the Tokyo Quantum Gateway (TQG) website. Built with Next.js (App Router), TypeScript, and SCSS modules.

The layout follows the desktop design mock. Designer annotation callouts (the blue squares and their comments) are not part of the interface.

Only the top page is included. Header, footer, and in-page buttons move between sections on this page.

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scripts

- `npm run dev` — start the development server
- `npm run build` — production build
- `npm run start` — run the production server
- `npm run lint` — lint the project

## Styling

Component styles live in `*.module.scss` files. Shared tokens, mixins, and the global reset are in `styles/`.
